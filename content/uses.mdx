# What I Use

This page lists the software, hardware, and tools that I use for development and daily work. I get asked about my setup quite often, so I thought I'd document everything here. This page is inspired by [uses.tech](https://uses.tech/).

## Development Environment

### Editor & IDE
- **Visual Studio Code** - My primary editor for web development
  - Theme: One Dark Pro
  - Font: JetBrains Mono with ligatures
  - Essential extensions: Prettier, ESLint, GitLens, Bracket Pair Colorizer
- **IntelliJ IDEA** - For Java development and larger projects
- **Vim** - For quick edits and server work

### Terminal
- **Windows Terminal** - Clean, fast, and customizable
- **PowerShell** - My shell of choice on Windows
- **Oh My Posh** - For a beautiful and functional prompt
- **Git Bash** - For Git operations and Unix commands

### Version Control
- **Git** - Version control system
- **GitHub** - Code hosting and collaboration
- **GitHub Desktop** - GUI for Git when I need visual diffs

## Programming Languages & Frameworks

### Frontend
- **TypeScript/JavaScript** - My primary language for web development
- **React** - Component-based UI development
- **Next.js** - Full-stack React framework
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React

### Backend
- **Node.js** - JavaScript runtime for server-side development
- **Express.js** - Web framework for Node.js
- **Python** - For scripting, data analysis, and backend APIs
- **Django/Flask** - Python web frameworks

### Databases
- **PostgreSQL** - My preferred relational database
- **MongoDB** - Document database for flexible schemas
- **Redis** - In-memory data structure store for caching
